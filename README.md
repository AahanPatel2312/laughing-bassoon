# aahan's portfolio

my personal site. one html file, no framework, no build step. i made it to learn how this stuff actually works instead of just copying a template.

i'm still learning so some of the code is probably not the "right" way to do it. it works though.

## what's in it

- `(https://aahanpatel2312.github.io/laughing-bassoon/#about)` - the whole site (html + css in one file)
- thats it. really.

sections: about, where i am with learning, things i've made, contact.


## why it looks like this

my first version had gradients, glowing blobs and progress bars for my skills. it looked like every other portfolio and honestly the bars were kind of made up (what does 55% python even mean?). so i threw it out and started again with something plain.

now its just text, a serif font and one red-ish color. i like it more.

## things i learned making it

- `max-width` on a column makes a page 10x more readable than full width text
- css grid for the project list instead of cards
- how `clamp()` works for font sizes, still not 100% sure about it tbh
- less is more, i know thats cliche but it's true
- my margins were wrong like 6 times
